About Safe Mode

Safe Mode provides enhanced protection against inappropriate content.

What Safe Mode Does:
  • Lowers the threshold for detecting NSFW media
  • Applies stricter URL filtering
  • Blocks more potentially unsafe content
  • Provides better protection for family-friendly servers
What Safe Display Mode Does:
  • Verbergt media en URLs in scanresultaten
  • Voorkomt dat gebruikers per ongeluk op ongepaste links klikken
  • Toont alleen een knop om de inhoud te bekijken
  • Ideaal voor servers met jonge gebruikers
Recommended Settings:
  • General Servers: Safe Mode Off or Low
  • Family-Friendly Servers: Medium + Safe Display Mode
  • Servers with Young Users: High + Safe Display Mode
